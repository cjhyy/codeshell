# 西木野真姬 · Scarlet Stage

CodeShell 桌面端主题包。以真姬的绯红应援色为主色，提供玫瑰白浅色模式和深酒红深色模式。

- 聊天区：舞台服立绘，靠右显示，保留正文阅读对比。
- 侧栏：制服立绘。
- 标题栏、输入框、面板：独立配色。
- 窗口外框：2px 绯红描边和 12px 圆角。

在支持界面皮肤的 CodeShell 桌面端打开 **设置 → 外观 → 导入主题包**，选择本目录（包含隐藏文件 `.cs-theme.json`），安装后会自动启用。压缩包请先解压，再选择解压后的目录。浅色、深色或跟随系统仍由外观模式控制。

主题未替换 Mimi；现有形象继续可用。旧版 CodeShell 只能读取其中的配色和传统背景字段，完整界面皮肤需要本次桌面端更新。
