# AGGREGATOR-R27-01 独立静态复核

支持 **1 项 P3 静态正式发现**，根因为输出文件身份时丢掉外部工作目录。没有新增候选或拆出第二项。本 reviewer 对作者报告之外的关键源码链、普通输入条件和旧记录做了独立读取；0 Git、0 产品/import/测试/fixture、0 React/browser/native、0 网络/模型执行。未观察真实点击、文件打开、React key warning 或磁盘行为。

独立源码链成立：DriveAgent 的 [isolation 与 cleanup 合同](../../../packages/coding/src/tools/drive-agent.ts:104) 支持 `isolation:"worktree", cleanup:"keep"`；[1164–1177](../../../packages/coding/src/tools/drive-agent.ts:1164) 将真正 launch cwd 设为创建的 worktree。[316–354](../../../packages/coding/src/tools/drive-agent.ts:316) 的 keep 只解锁保留，auto 在有改动时同样选择 keep；没有先合并或复制回父工作区。此例无需外部 CLI 自行 cd、歧义相对 Edit 参数、异常 DTO、失败清理或旧目录猜测。

[normalizeChangedFiles](../../../packages/coding/src/tools/drive-agent.ts:453) 把工作树内文件变成 job cwd-relative，完成处理 [784–806](../../../packages/coding/src/tools/drive-agent.ts:784) 与通知 [834–859](../../../packages/coding/src/tools/drive-agent.ts:834) 仍携带正确 job cwd。[renderer](../../../packages/desktop/src/renderer/types.ts:1986) 保留此 cwd 到 system marker。随后 [displayExternalPath](../../../packages/desktop/src/renderer/messages/fileChangeAggregator.ts:81) 和 [295–300](../../../packages/desktop/src/renderer/messages/fileChangeAggregator.ts:295) 已经得到了不同的 absolute identity，却在 [331–335](../../../packages/desktop/src/renderer/messages/fileChangeAggregator.ts:331) 发布仅含相对 display path 的 FileEditEntry；[366–372](../../../packages/desktop/src/renderer/messages/fileChangeAggregator.ts:366) 的显式 identity 并没有保留进输出字段。

[ChatView](../../../packages/desktop/src/renderer/ChatView.tsx:1818) 与 [MessageStream](../../../packages/desktop/src/renderer/MessageStream.tsx:609) 给整张卡的是父聊天 conversationRoot。文件行 [258–265](../../../packages/desktop/src/renderer/messages/FilesChangedCard.tsx:258) 用 `f.path + cwd`，再经 [openWith](../../../packages/desktop/src/renderer/chat/openWith.ts:36)、[bucket](../../../packages/desktop/src/renderer/app/usePanelBuckets.ts:938) 到 [FilesPanel](../../../packages/desktop/src/renderer/panels/FilesPanel.tsx:228)，相对路径按 revealFile.cwd join。因而父聊天 `/repo`、job `/isolated`、文件 `src/a.ts` 的普通例子，在源码上请求父目录的 `/repo/src/a.ts`，无法保留 `/isolated/src/a.ts` 的身份。父目录同名文件存在时指错另一文件，否则该行不能定位目标。原 marker/job/lifecycle 信息仍可用于手工定位，不能夸大为内容删除或数据丢失。
