# 优化实验室样本编辑器

本轮交付 P1b 中可独立使用的完整样本编辑，不包含运行证据导入、实验室内候选试用或 P2 采用。以 v0.9.25 的已发布代码为基线，复用现有样本契约、冻结器、授权和执行流程。

## 行为与边界

- 表单编辑数据集标题、任务族及全部案例字段；支持案例增删、复制，rubric 和三类硬断言编辑。复制产生新案例 ID，保持原 sourceGroupId，避免把同源材料伪装为独立证据。
- JSON 与表单保留语义，包括可选 expected 的缺省/空文本、JSON 比较值的 string/number/boolean/null 和路径分段。结构不支持或非法 JSON 留在原文视图修复，不静默丢弃未知字段。
- 后端 validate_dataset 是权威校验，逐项显示错误、独立来源组数量与探索性警告；编辑后旧校验失效。冻结材料仍按内容 hash 生成新 artifact，既有计划、授权、评分和报告不覆写。
- 原生选择本地 JSON 导入/导出，保留原文用于修复；只处理有界普通文件，不跟随符号链接。对话框完成后重新检查窗口、开关、项目主目录与信任状态。导出不允许覆写实验内部 artifact。
- 草稿以不透明 project ID 在当前窗口内隔离，切项目或离开页面不串材料；关闭窗口即结束保留，长期保存须导出。没有将样本内容写入浏览器 localStorage，也没有新增自动后台读取。
- 编辑、导入、导出、校验和准备计划均不调用模型；原生授权后仍须单独开始。迟到响应不能作用于另一项目。

## 验证

纯转换和组件测试覆盖全字段、可选值、三类断言、增删复制、错误反馈和 JSON 修复；Page 测试覆盖项目隔离、取消导入、迟到文件和校验响应。Main/preload 测试覆盖原生边界、有界 UTF-8 文件、符号链接及目标更换。真实 Electron 验收在隔离 HOME 中编辑并冻结样本，再运行既有本地假服务实验和崩溃恢复流程。

226 项相关测试、变更文件 ESLint、全仓构建/类型检查、Desktop 构建及真实 Electron 验收已通过。Electron 实际操作覆盖表单编辑、增删复制、资料/证据/JSON 路径换行与数字类型、原生文件往返、非法 JSON 修复、同窗口离页草稿、真实冻结以及原有完整实验/人工评分/撤销/停止/worker 与应用崩溃恢复流程。发布包审计通过 9 个 tarball、47 个严格 NodeNext 类型入口和 45 个运行时导入。实验请求只发给本地假服务；编辑与准备阶段请求数为零。本次没有真实付费模型实验或真实收益结论。CI 与三平台安装包预检为后续合并/发布门槛，最终结果见 [PR #58](https://github.com/cjhyy/codeshell/pull/58)。
