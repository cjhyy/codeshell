# 本地／云端项目、跨设备 Panel、Link：总实施清单

更新：2026-09-23。状态：实施中，尚未发布完整版本。

## 产品原则

同一个 Panel 产品面向本地项目和云端项目。项目决定执行环境、文件位置、数据、后台任务及安装版本；电脑和手机是操作入口。打开同一个项目必须看到同一套项目状态，切换设备不迁移任务。不同项目允许选择不同 Panel 版本，能力差异由 Host 显式声明。

- 电脑本地项目：电脑执行；云端服务离线不妨碍本地操作。
- 电脑云端项目：独立云端工作台登录，云端执行。
- 手机本地项目：配对并远程控制电脑；电脑离线时显示离线。
- 手机云端项目：直接登录云端；不依赖电脑在线。
- Link：独立管理第三方连接和受限授权；其故障只影响依赖该连接的功能。

## 仓库与部署边界

| 仓库 | 负责 | 不搬入的内容 |
| --- | --- | --- |
| `codeshell` | Core、Desktop、共享 Web、Panel Host、项目执行和连接基础包 | Panel 的模型、编辑规则、业务脚本 |
| `codeshell-panel-apps` | 六个 Panel、业务原生入口、客户端辅助库、独立版本 | Agent 引擎、服务器身份和主机权限 |
| `codeshell-services` | 独立 Link、云端控制产品入口、部署配置、运维工具 | Core 源码、桌面仍依赖的整个 `packages/server` |

服务仓库已在本地建立，但还没有远程仓库和公开发布。它通过固定公开包版本组合云端产品。拆仓库与拆部署单元分别安排；首版仍可在一台服务器部署。

服务器至少有三个独立运行单元：

1. **Cloud 控制服务**：账号、初始化、项目目录和生命周期、工作台入口、项目路由。
2. **项目执行环境**：各项目 Docker 容器和数据卷，实际运行 Agent、Panel 任务及程序。
3. **Link 服务**：第三方授权、下游应用授权、凭据加密和只读数据动作。

反向代理负责 Cloud / Link 各自域名与 HTTPS。电脑执行器属于桌面产品；后续安全中继是另一项连接能力，不能用 Link OAuth 服务替代。现阶段 Cloud 控制服务是宿主机 Node 进程，不直接套用单工作区 Compose。

## 工作包 C：Panel 版本与升级（codeshell + Panels）

- [ ] UI、原生入口、后台任务使用同一份经过确认的包内容。
- [ ] 安装包不可变；项目升级不覆盖其他项目正在使用的包。
- [ ] 首阶段在受影响任务结束后升级；之后实现多版本并行。
- [ ] 任务记录启动包版本，恢复时验证原包是否仍可用。

完成标准：两个项目使用不同版本互不影响；手机与电脑进入同一项目时版本一致；更新不能让旧任务突然执行新脚本。

## 工作包 D：六个 Panel 完整适配（codeshell-panel-apps）

每项都覆盖电脑本地、电脑云端、手机本地、手机云端，并使用真实产物验收。

| Panel | 必须完成的业务流程 | 特别检查 |
| --- | --- | --- |
| 下载 | 搜索／添加 → 队列 → 后台下载 → 取消／恢复 → 预览／保存 | 队列脱离页面、目录授权、跨平台依赖、账号选择 |
| 求职 | 资料／职位 → 文档编辑 → 录音／转写 → 自动化 → PDF 下载 | 手机录音、文档冲突、个人数据所属项目 |
| 投资 | 数据源 → 更新 → 研究 → 保存 → 自动化／提醒 | 连接范围、定时任务、来源与时效 |
| 视频 | 导入／采集 → 编辑 → 处理 → 保存 → 导出／下载 | 大文件资源、后台渲染、设备录音、恢复 |
| 设计 | 创建／导入 → 测量 → 画布编辑 → 预览 → 保存／导出 | 触控、窄屏、坐标、资源引用、编辑冲突 |

所有模型、依赖版本、安装策略和业务规则留在 Panel。无法在 Linux/手机完成的操作需要经过验证的适配，不能仅隐藏按钮。

## 实施顺序与发布门槛

1. A 项目路由 + B 公共任务／资源能力，先完成下载 Panel 四组合闭环。
2. C 项目版本绑定；将 B 的恢复和冲突处理扩展到其余 Panel。
3. D 六个 Panel 全流程，与 E 手机交互同步验收。
4. F Link 可独立推进，再完成 Host 接入；G 部署演练随服务成熟逐项进行。
5. E 统一设备目录／中继／通知，最后综合验收与 G 版本发布。

每个组合检查：执行位置、真实输出、持久化、重复提交、断线恢复、权限撤销、版本更新。单元测试、模拟浏览器、真实 Docker、真实服务商、物理手机分别记录，不能互相代替。

不列入首版必要范围：本地／云端自动同步、跨主机任务迁移、公开多租户平台、多节点调度、不可信代码托管、完全离线执行、原生手机 App。
