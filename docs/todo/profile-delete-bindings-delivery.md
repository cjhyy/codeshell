# 删除数字人时完整解绑会话

强制删除现在通过单遍异步扫描处理全部持久会话，包括归档会话，不再只处理查询上限内的前 100 项，也不反复从头读取全部历史。每次异步文件读取让主线程继续处理其他工作。清除绑定使用 SessionManager 的字段级 CAS：每次重试重新检查目标数字人，其他 writer 已选择的新数字人不被覆盖。

绑定写入失败会在修改团队、当前项目默认或数字人定义前退出并保留定义。已经成功的解绑不回滚；解除失败原因后可以重试。删除定义前再执行一次异步扫描；发现重新绑定或新建会话的绑定时保留定义，避免明确可见的残留绑定。文件在打开或读取时发生变化会让操作失败并保留定义，不把并发原子替换当作不存在的引用。

会话、归档标记、标题与原聊天记录均保留，其他数字人的绑定不改。此操作沿用现有本机会话扫描及当前项目范围；不声称与任意外部进程的新建会话、其他项目默认设置和数字人删除形成全局事务。

验证使用隔离 HOME 与真实 state 文件：205 个会话、归档项、其他绑定及原 transcript 字节；真实持有的状态锁阻止解绑时保留定义、团队及当前项目默认，释放后成功重试。Core 的受控 CAS 边界插入真实竞争写入，验证新版绑定及标题保留，条件不满足时不写入或增加 revision。扫描间插入真实重新绑定及新建会话，验证最终检查保留定义且重试可完成。异步扫描隔离损坏及符号链接状态，沿用归档过滤语义。

最终扫描的受控 open 边界执行真实 SessionManager 标题写入并原子替换状态文件；验证操作失败、重新绑定和新标题均保留，之后可以重试完成。
