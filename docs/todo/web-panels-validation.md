## 已知边界

当前源码已超出基础 Web 运行范围，但并未实现原生 Panel SDK 的全部接口。已接入的方法取决于宿主返回的 `availableMethods` 和实际安装的程序。本机 Hub 已更新，其他部署和历史镜像仍需自行构建升级。Cookie、音频、媒体、自动化、PDF 等仍未完整接入，Mimi 面板历史尚未持久保存，进程确认也不等于完整沙箱。GitHub 匿名访问限流不会影响已经安装的面板。
