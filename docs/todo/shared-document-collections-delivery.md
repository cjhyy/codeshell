# 可复用资料集首版

在现有设置的“资料集”入口创建命名资料集，再在项目设置中引用其当前清单或指定文件。普通流程不要求源 ID、适配器配置或 JSON；原有 mock、MCP 和 Link 源保留在折叠的高级区域。没有新增侧边栏。

## 已实现

- 本机文件保留原位置，只保存路径、文件身份和内容版本；不同项目引用同一清单，无项目间文件复制。
- 本地选择器可以添加多个文件，或添加一个文件夹当前的普通文件清单。排除隐藏项和符号链接，最多递归 12 层、检查 2000 个目录项，一次最多 100 个文件及 100 MiB，每文件最多 20 MiB。再次选择相同路径保留文件 ID；目录后续新增项不会自动加入资料集。
- 公网 HTTPS 静态文件地址在显式添加或更新时下载并记录大小与 SHA-256。列表不联网，不建立持久正文副本。读取时重新下载并验证保存的版本；变化、删除、无法访问均拒绝返回旧版本，用户可显式更新。
- 链接只执行无账号、无 Cookie 的 GET；禁止私网目标，绑定经核验的 DNS 地址及实际 TLS 对端，只接受同源 HTTPS 重定向，最多三跳、总计 30 秒及 20 MiB。不会复用第三方连接权限。
- 清单中的每个文件独立成为一个 scope/resource。项目“当前全部文件”保存当时明确的文件 ID；新增文件不会自动扩大项目权限。Profile 继续求交，空范围仍无权限。UI 读取原始项目 binding，当前 Profile 排除的绑定仍能编辑和解除。
- ReadSource 逐文件审批、撤权和最终版本检查沿用现有边界。复用 UTF-8、Office 和 PDF 的有界解析及词法 query/chunk；PDF 仍需既有 Host managed Node 与可选解析依赖。集合读取不授予任意本地文件工具权限。
- 静态链接的解析文件名使用已核验下载的最终地址及受支持的响应类型（PDF、DOCX、PPTX、XLSX），因此无扩展名下载地址和同源重定向也能选择正确解析器。旧清单读取时重新派生解析名，无需迁移；原条目 ID、请求地址、大小及 SHA-256 校验不变，泛型响应仍保留旧文件名提示。
- 本地清单显示文件变化或失效；链接显示上次检查时间。显式更新保留文件 ID，失败保留原清单。修改使用目录锁内 revision CAS；过期窗口、选择器等待期间的更新、主窗口导航和销毁均不能提交旧修改。
- 移除条目、解除项目引用及删除资料集均不删除原始文件。删除前展示本机已登记且可访问项目的引用影响；删除后原项目绑定显示为失效引用，用户可解除。

## 兼容与首版边界

现有项目 uploads 不迁移、不自动分享，保留为“本项目文件”，隐藏重复的内置源展示。原 Link/MCP/mock 源与权限语义保留。文件夹为显式清单，不是后台同步目录；文件移动后可移除失效条目并重新选择。新增条目需要项目重新勾选。

旧版 Host 不识别新增的 collection kind；本版不承诺新旧 Host 同时修改同一个数据目录时保留资料集配置。原文件始终独立保留。

本版未新增网盘接入、第三方账号/OAuth、自动同步、云端文件托管、跨设备文件访问、OCR、向量索引或资料集跨 scope 搜索。现有 uploads 的显式多文件词法查询保留。解析索引仍为有界进程缓存，原件或 URL 版本检查不会被缓存跳过。

## 验证

使用仓库隔离 HOME 的 guarded Bun runner 验证 Core schema/CAS、真实 ToolExecutor 的逐文件审批与 Profile 交集、原件替换/撤权、Office 解析、两项目复用及范围固定、Main 原生选择流程的受控 fixture、窗口生命周期和实际 React 交互。URL 传输测试在首个 Core 导入前安装网络拒绝 guard，使用精确合成 origin 的内存 TLS/HTTP 事件 fixture，验证 DNS/IP/TLS 参数、大小、重定向、取消、超时与版本变化；这不等同真实公网或网盘账号验收。构建和全 workspace 类型检查另行执行。

无扩展名链接回归经过真实 Main 新增/更新清单与 Core adapter，使用真实 PDF/Office 文档字节及隔离解析进程，验证同源重定向、响应类型、旧记录兼容，以及已有索引缓存时仍拒绝变化的链接正文。传输仍是上述内存 fixture，未请求真实公网。

交付为源码集成；安装包与发行以实际 release 记录为准。
