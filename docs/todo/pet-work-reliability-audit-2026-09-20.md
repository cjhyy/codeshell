## 实施与验收记录

实现已落盘；本文件保留审计历史，根目录 TODO 只保留后续加载/部署验收。

- Pet 自动收尾继续原 Session，显式续跑参数无效时返回错误。`originalObjective` 与恢复提示分开保存，续办重放也校验原 Session。启动前失败的 ledger 重放不能误报已启动。
- 候选读取 transcript 最后 512 KiB，过滤 injected / 非用户 authority / 工具结果；每个候选最近请求、结果各 180 字，详细内容通过 Sessions describe 查看。候选数量和 scope 边界沿用现有实现。
- MCP 默认初始化期限 30 秒，仅超时额外重试一次，可通过 `connectTimeoutMs`（1–120000）和 `connectRetries`（0–2）配置。同一截止时间覆盖握手与工具发现；进程组清理完成后才重试，真实测试覆盖 wrapper 和孙进程。失败按当前 scope 进入模型临时上下文；恢复后清空，不写入持久化历史。
- 图片在同一 run 保留最多 6 次成功模型响应，历史最多 4 个图像出现位置、8 MiB 编码数据。新附件首次呈现不受历史窗口限制；之后受所有上限限制。压缩可更早淘汰，跨新 run 的历史图片仍需明确回读。
- `max_turns` 不再进入自然完成/Goal 成功判定。Pet 保留未完成检查点，沿用既有 failed 终态触发有界续办；没有新增协议枚举。
- browser 和 Pet 提示补充了对象来源、行号对应、异常分类、回执证据与不确定性约束。这是模型行为防护，不是结构化外部写入验证器，不能保证模型永不识别错截图。
