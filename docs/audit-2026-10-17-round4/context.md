## CTX-1 / P2 — Fallback snipping cuts the result away from a retained prefix tool call

The default `snipCompact(messages, 3, 8)` protects only the beginning of the retained tail. If message index 2 is an assistant tool call and index 3 is its completed result, it retains the call in the first three messages but drops the result in the middle. This turns valid conversation history into an incomplete provider sequence. A normal early run with injected standing instructions, the user's first task, and an assistant tool call has this shape.

**Exact implementation:** [compaction.ts:324](../../packages/core/src/context/compaction.ts#L324)–342 adjusts `lastStart` only and copies `messages.slice(0, keepFirstN)` without protecting its closing boundary. [manager.ts:635](../../packages/core/src/context/manager.ts#L635)–640 invokes this fallback after unavailable/failed/no-progress summarization when pressure remains over the normal compact gate. The sync fallback is also at 489; manual fallback at 712. The contract is explicit in [compaction.ts:10](../../packages/core/src/context/compaction.ts#L10)–11 and the actual ordered-pair validator [transcript.ts:94](../../packages/core/src/session/transcript.ts#L94)–119. Provider conversion retains the dangling tool call: [anthropic.ts:450](../../packages/core/src/llm/providers/anthropic.ts#L450)–456.

**Actual caller and impact:** [turn-loop.ts:1068](../../packages/core/src/engine/turn-loop.ts#L1068)–1069 manages context, then 1140 sends it to the model; no pair repair runs between those operations. With a temporarily unavailable summarizer, the real ContextManager and real TurnLoop sent the incomplete history to both fake model attempts and returned `model_error`. The late error-exit repair at 1191/2357–2401 inserts a cancellation result after rejection, losing the original successful result in working context. This can interrupt a long ordinary run precisely when the fallback should recover context pressure. No real provider rejection was executed; the adapter uses Core's real pair validator, while provider contract and wire forwarding are source evidence.

**Evidence:** [context-snip-pairs.test.ts](evidence/context-snip-pairs.test.ts), [raw first-run log](evidence/context-snip-pairs.first.log), [first exit](evidence/context-snip-pairs.first.exit.txt). 2 tests, 15 assertions, 0 failures/skips, Completed, exit 0. One test compares the broken default prefix boundary with a complete-prefix control; the other runs real ContextManager + TurnLoop with owned in-memory model/hooks/transcript/executor adapters. The configured window places the initial history at 88% pressure; no invalid history was supplied by the fixture. No executable tool, filesystem read, network, SDK client or full Engine/host process was used.

**Correction direction:** protect both snip boundaries and retain/remove complete tool rounds before forwarding. Do not treat a later synthetic cancellation result as restoration of the original tool outcome. No correction was made.

## CTX-2 / P2 — Summary serialization silently drops all text inside structured tool results

`tool_result.content` can be a text/image block array. Normal summary serialization converts every such result to an empty string, including its text facts. The summarizer therefore never receives the result's text, yet a successful summary replaces the entire old span. Measurements, diagnostics, paths or conclusions found only in that result disappear from the working conversation.

**Exact implementation:** [compaction.ts:842](../../packages/core/src/context/compaction.ts#L842)–844 serializes array content as `""`. This is a supported ordinary contract: [turn-loop.ts:249](../../packages/core/src/engine/turn-loop.ts#L249)–255 forwards `ToolResult.contentBlocks` verbatim, [transcript.ts:265](../../packages/core/src/session/transcript.ts#L265)–279 replays it, and provider conversion retains nested text ([anthropic.ts:461](../../packages/core/src/llm/providers/anthropic.ts#L461)–465). A concrete producer is an opted-in vision-capable MCP server: [mcp-manager.ts:715](../../packages/core/src/tool-system/mcp-manager.ts#L715)–718 emits wrapped text plus inline images; 1621–1625 and 1731–1735 call that formatter. The schema supports `inlineImages` at [schema.ts:396](../../packages/core/src/settings/schema.ts#L396). The separate portable context serializer already retains nested text at [compaction.ts:913](../../packages/core/src/context/compaction.ts#L913)–930; this finding is about normal compaction/range archival, not context-package transfer.

**Actual callers and impact:** automatic compaction calls the lossy builder and replaces the span at [manager.ts:319](../../packages/core/src/context/manager.ts#L319)–332. Range archival shares it at 758–769; [engine.ts:4539](../../packages/core/src/engine/engine.ts#L4539) consumes the result and may persist the anchored archive at 4550–4551. Manual `/compact` shares the same summary attempt via manager 697–705 and engine 4374. A faithful model cannot recover facts omitted from its input. Original transcript events are retained; this is loss of active summary context, not deletion of the original history.

**Evidence:** [context-structured-summary.test.ts](evidence/context-structured-summary.test.ts), [raw first-run log](evidence/context-structured-summary.first.log), [first exit](evidence/context-structured-summary.first.exit.txt). 2 tests, 14 assertions, 0 failures/skips, Completed, exit 0. Actual `toolResultToBlock`, ContextManager automatic summary and range archival run with a deterministic in-memory summarizer. It includes the owned measurement fact only when the real prompt contains it. Structured result facts are absent both from the prompt and final compacted history; scalar result controls preserve the exact same fact, and the original input remains intact. Portable-package serialization is a positive control. No real MCP server or model ran; the fixture uses a supported text-only array, with the MCP text-plus-image producer established by source reading. Manual `/compact`, Engine persistence and full host behavior were not dynamically executed.

**Correction direction:** use the existing recursive structured serializer, or equivalent bounded nested text serialization, for normal summaries and archival. Represent media explicitly rather than suppressing accompanying text. No correction was made.
