# Mimi character pack pipeline

`generate.sh` makes one row strip per move with Codex's image tool, and `assemble.py` turns the strips into `src/renderer/assets/mimi-papillon/performer-v1.webp` (cut out, despilled, measured) and checks scale.

To change or replace the character, read the guideline first: `docs/superpowers/specs/2026-10-30-mimi-character-pack-guideline.md`.
